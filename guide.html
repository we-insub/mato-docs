Mato 처음 사용 설명서

Mato는 내 PC의 Chrome 브라우저와 앱 창을 Codex, Claude, Antigravity 같은 AI 앱에 연결해 주는 도구예요. 이 설명서 순서대로 따라 하면 코딩을 잘 몰라도 처음 설치부터 멤버십 무제한 인증까지 한 번에 마칠 수 있어요.

Google 로그인 필수 로그인이 끝난 계정만 브리지 연결과 브라우저 제어, AI 연결 기능을 쓸 수 있어요. 비회원은 어떤 기능도 사용할 수 없어요.
1. 준비물 2. 로컬 브리지 설치 3. 약관 동의·로그인 4. 브라우저 연결 5. AI 앱 연결 6. 멤버십 무제한 인증 7. 화면별 기능 안내 8. 로그아웃·회원탈퇴 9. 자주 묻는 질문 10. 문의하기

1. 시작하기 전에 준비할 것

  • Google Chrome 브라우저 (Windows 또는 macOS 13 이상)
  • Node.js 22.13 이상 — AI 앱과 Chrome을 이어 주는 로컬 브리지 프로그램이 Node.js 위에서 실행돼요.
  • Google 계정 — Mato 로그인과 유료 멤버십 확인에 꼭 필요해요.
Node.js가 설치돼 있는지 모르겠다면 Windows에서는 PowerShell, Mac에서는 터미널을 열고 node -v를 입력해 보세요. v22.13.0 이상이 나오면 바로 다음 단계로 넘어가면 돼요.

2. 1단계: 내 PC에 로컬 브리지 설치하기

Chrome 확장 프로그램은 보안상 내 PC의 AI 앱과 직접 통신할 수 없어서, 중간 다리 역할을 하는 로컬 브리지를 내 PC에 한 번 등록해야 해요.

  1. 다운로드한 Mato 압축 파일을 바탕화면이나 문서 폴더처럼 위치가 바뀌지 않는 폴더에 풀어 두세요. 설치 뒤에 폴더 이름을 바꾸거나 옮기면 연결이 끊겨서 다시 설치해야 해요.
  2. OS에 맞게 아래 설치 명령을 한 번 실행하세요.
    • Windows: Mato 폴더에서 PowerShell을 열고 .\install.ps1을 실행하세요.
    • macOS: 터미널을 열고 Mato 폴더로 이동한 뒤 node install-macos.mjs를 실행하세요. 앱 창 제어까지 쓰려면 Xcode Command Line Tools(xcode-select --install)가 필요해요.

3. 2단계: 확장 열기, 약관 동의와 Google 로그인

  1. Chrome 오른쪽 위 확장 프로그램 아이콘에서 Mato를 눌러 창을 여세요. 화면이 좁게 느껴진다면 맨 아래 페이지 열기를 눌러 큰 화면으로 띄워 두고 쓰면 편해요.
  2. 맨 위 Google 계정 카드에서 이용약관과 개인정보처리방침을 확인한 뒤 동의 체크박스를 누르세요. 체크해야 로그인 버튼이 열려요.
  3. Google로 로그인을 누르고, Mato에서 사용할 본인 Google 계정을 선택하세요.

참고: Chrome 웹 스토어가 아닌 개발자 모드로 직접 폴더를 불러온 경우에는 chrome://extensions에서 개발자 모드를 켠 뒤 Mato\extension 폴더를 선택해 추가하면 돼요.

4. 3단계: 로컬 브리지 연결과 브라우저 이름 정하기

  1. 브라우저 연결 카드에서 파란색 로컬 브리지 연결 버튼을 누르세요. 오른쪽 배지가 ● 연결됨으로 바뀌면 준비가 끝난 거예요.
  2. 브라우저 이름 칸에 집 노트북, 회사컴처럼 알아보기 쉬운 이름을 적고 이름 저장을 누르세요. 여러 PC나 Chrome 프로필을 함께 쓸 때 AI가 어느 창을 조작할지 헷갈리지 않아요.
연결이 안 될 때 “로컬 연결을 열 수 없습니다”가 뜨면 2단계의 설치기(install.ps1 또는 node install-macos.mjs)를 아직 실행하지 않았거나 설치 뒤에 Mato 폴더를 옮긴 경우예요. 설치기를 다시 실행한 뒤 연결 버튼을 누르세요.

5. 4단계: 사용하는 AI 앱에 Mato 연결하기

MCP 연결 안내 막대를 눌러 펼친 뒤 내가 쓰는 AI 앱에 맞춰 등록하면 돼요.

  1. 사용할 앱 목록에서 Codex, Claude Code, Claude Desktop, Antigravity 중 하나를 고르세요.
  2. 아래 상자에 내 PC의 OS(Windows 또는 macOS)와 Node 경로에 맞는 안내 문구가 자동으로 채워져요.
  3. 프롬프트 복사 버튼을 누르고, 그 AI 앱 대화창에 그대로 붙여넣어 실행하세요. AI가 설정을 마친 뒤 내 브라우저 이름(예: 회사컴)을 알려주면 연결에 성공한 거예요.

6. 5단계: 마토 유튜브 유료 멤버십 무제한 인증하기

기본 계정도 Google 로그인을 마치면 바로 쓸 수 있지만 하루 호출 수와 동시 연결 수에 제한이 있어요. 마토 유튜브 채널 유료 멤버십 회원이라면 간단한 인증만으로 제한 없이 쓸 수 있어요.

구분 하루 MCP 호출 동시 연결 PC · 브라우저 병렬 동시 처리
일반 로그인 계정 하루 500회 (매일 오전 2시 초기화) PC 2대 · 브라우저 2개 최대 3개
유료 멤버십 인증 회원 횟수 무제한 PC 5대 · 브라우저 5개 최대 10개

멤버십 인증 순서

  1. MCP 연결 안내를 펼친 뒤 내 멤버십 확인 버튼을 누르세요.
  2. Google 권한 창이 열리면 멤버십에 가입한 본인 YouTube 채널 계정을 선택해 허용하세요.
  3. 허용이 끝나면 등급 배지가 유료 멤버십으로 바뀌고 오늘 사용량이 무제한으로 전환돼요.
PC 사양에 맞춘 병렬 개수 조절
유료 멤버십은 최대 10개까지 동시에 돌릴 수 있지만, 개인 PC 사양(CPU·메모리)에 따라 창이 많아지면 느려질 수 있어요. 이럴 때는 AI 에이전트에게 “병렬은 3개씩만 실행해 줘”처럼 MCP 명령으로 원하는 대수를 직접 줄여서 지시하면 쾌적하게 쓸 수 있어요.
반대로 일반 계정이 7개처럼 등급 한도를 넘는 병렬 작업을 요청하면 Mato Chrome 확장이 등급 한도(최대 3개)에 맞춰 자동으로 차단해요.

안내: 일일 호출 수는 매일 한국시간 오전 2시에 0으로 초기화돼요. 비정상 종료된 브라우저 연결 자리는 마지막 응답 후 90초가 지나면 자동으로 비워져요.

7. 대시보드 카드별 상세 사용법

브라우저 연결 · 기기 관리

같은 Google 계정으로 연결된 PC와 브라우저 목록을 보여 줘요. PC나 브라우저 한도가 다 찼다면 체크박스로 안 쓰는 기기를 고른 뒤 선택한 연결 해제를 누르면 자리를 비울 수 있어요.

현재 탭

  • 본문 읽기: 지금 보고 있는 웹페이지 글과 버튼 목록을 읽어요.
  • 화면 캡처: 현재 탭 화면을 PNG 이미지로 찍어 저장해요.
  • 탭 진단 켜기: 콘솔 로그, 같은 사이트 네트워크 응답, 성능 측정, 키 입력, 좌표 클릭까지 써야 할 때 먼저 켜세요.
  • GIF 녹화: 화면이나 탭을 최대 640×480, 초당 5프레임, 30초 길이의 GIF로 녹화해 저장해요.

탭 목록

열린 탭을 창별로 묶어 보여 줘요. 위쪽 드롭다운에서 같은 PC에 연결된 다른 Chrome 프로필을 고르거나 창 필터로 원하는 창만 추려 볼 수 있어요. 탭 이름을 누르면 그 탭으로 바로 넘어가고, 오른쪽 × 버튼을 누르면 탭을 바로 닫아요.

앱 창 공유

브라우저가 아닌 Windows나 Mac의 다른 프로그램 창을 AI가 조작하게 할 때 써요. 창 선택을 눌러 직접 고른 창만 제어되며, 작업이 끝나면 공유 중지를 눌러 언제든 멈출 수 있어요. Mac은 처음 쓸 때 시스템 설정에서 손쉬운 사용과 화면 기록 권한을 켜야 해요.

추가 도구 권한

  • 전체 사이트 허용: 끄면 아래 이 사이트 허용 버튼으로 지정한 사이트만 AI가 읽고 조작해요.
  • 조사 완료 시 AI가 연 탭 닫기: 켜 두면 AI가 조사하려고 새로 연 탭을 작업이 끝났을 때 자동으로 닫아 줘요.
  • 병렬 실행: 여러 작업을 한꺼번에 처리할지 고르며, 한도는 계정 등급(일반 3개 · 멤버십 10개)에 맞춰 확장에서 자동으로 막아 줘요. 멤버십 회원도 PC가 느려지면 AI에게 “한 번에 4개만 병렬로 해 줘”처럼 직접 대수를 낮춰 지시할 수 있어요.
  • 북마크 · 방문 기록 · 다운로드 허용: AI가 내 북마크, 방문 기록, 다운로드 목록을 조회해야 할 때만 필요에 맞게 켜세요.

8. 로그아웃과 회원탈퇴

  • 로그아웃: Google 계정 카드 오른쪽의 로그아웃을 누르면 로컬 브리지 연결도 함께 끊기고 모든 도구가 잠겨요. 언제든 다시 로그인해 쓸 수 있어요.
  • 회원탈퇴 (재가입 불가): 로그아웃 옆 회원탈퇴를 누르고 확인하면 연결된 PC·브라우저·사용량·YouTube 채널 연동 기록이 서버에서 모두 삭제돼요. 탈퇴 처리가 끝나면 같은 Google 계정으로는 다시 가입하거나 Mato를 쓸 수 없어요.

9. 자주 묻는 질문

유료 멤버십에 가입했는데도 일반 등급으로 나와요. 어떻게 하나요?

MCP 연결 안내를 열고 내 멤버십 확인을 눌러 멤버십에 가입한 YouTube 채널을 연결해야 해요. 멤버십에 방금 가입했다면 운영자 명단 갱신(최대 하루 1회) 뒤 자동으로 반영돼요.

AI가 웹페이지 내용을 못 읽는다고 해요. 왜 그런가요?

chrome://으로 시작하는 브라우저 내부 설정 페이지는 보안상 제어할 수 없어요. 일반 웹페이지(http:// 또는 https://)인지 확인하고, 추가 도구 권한에서 전체 사이트 허용이나 이 사이트 허용이 켜져 있는지 확인해 주세요.

회사를 옮기거나 PC를 바꾸면 어떻게 연결하나요?

새 PC에서 1단계 설치와 로그인을 마친 뒤 기존 PC가 한도에 걸렸다면, 브라우저 연결 → 연결된 PC에서 예전 PC를 체크해 선택한 연결 해제를 누르면 돼요.

10. 문의 및 지원 안내

설치 오류, 멤버십 인증 문의, 버그 제보는 별도 이메일이나 외부 사이트가 아니라 마토 유튜브 채널(@Mato_coder) ↗을 통해 남겨 주세요.

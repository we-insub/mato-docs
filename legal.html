Mato 이용약관 및 개인정보처리방침

시행일: 2026년 11월 27일 · 운영 채널: 마토(@Mato_coder) ↗ · 공식 문서: we-insub.github.io/mato-docs ↗

Mato Chrome 확장 프로그램과 로컬 브리지를 사용하려면 아래 이용약관과 개인정보처리방침을 확인하고 동의해야 해요. 궁금한 점은 YouTube 채널을 통해 문의할 수 있어요.

제1부 · 이용약관 제2부 · 개인정보처리방침 문의처 안내

제1부 · Mato 이용약관

제1조 (서비스 내용)

Mato는 사용자의 PC에 설치된 Google Chrome 브라우저와 로컬 앱 창을 사용자가 직접 지정한 로컬 MCP 클라이언트(Codex, Claude, Antigravity 등)에 연결해 웹페이지 조회, 탭 관리, 화면 캡처, 앱 창 제어 기능을 제공하는 도구예요.

제2조 (이용 자격 및 로그인 의무)

  1. Mato는 Google 계정 로그인 필수 서비스예요. 로그인하지 않은 비회원은 로컬 브리지 연결, 브라우저 제어, MCP 호출 등 모든 기능을 사용할 수 없어요.
  2. 사용자는 확장 화면의 이용 동의 체크박스에 동의하고 본인 명의의 Google 계정으로 로그인해야 해요.

제3조 (이용 한도 및 유료 멤버십 혜택)

  • 일반 로그인 계정: 하루 MCP 호출 500회(매일 한국시간 오전 2시 초기화), 동시 연결 PC 2대 · 브라우저 2개, 병렬 실행 최대 3개까지 쓸 수 있어요.
  • 마토 유튜브 유료 멤버십 인증 회원: 내 멤버십 확인을 통해 YouTube 채널 인증을 마치면 호출 횟수 제한 없이 동시 연결 PC 5대 · 브라우저 5개, 병렬 실행 최대 10개까지 쓸 수 있어요.
  • 회원 혜택은 마토 채널(@Mato_coder)의 유효한 유료 멤버십 명단(24시간 주기 갱신)을 기준으로 적용되며, 멤버십을 해지하면 다음 명단 갱신 시점부터 일반 한도로 돌아가요.

제4조 (금지 행위)

사용자는 Mato를 아래 목적으로 사용해서는 안 돼요.

  • 타인의 Google 계정·YouTube 채널을 도용하거나 인증·한도 시스템을 우회하는 행위
  • 스팸·악성 자동화·무단 대량 수집·서비스 방해 등 불법적이거나 타인의 권리를 침해하는 행위
  • 로컬 브리지나 계정 서버에 비정상 요청을 반복 전송해 서비스 안정성을 해치는 행위

제5조 (로그아웃, 회원탈퇴 및 재가입 제한)

회원탈퇴 후 재가입 불가 사용자가 회원탈퇴를 실행하면 계정의 기기 연결, 사용량, YouTube 채널 연동 정보가 모두 삭제되며, 탈퇴한 Google 계정으로는 다시 가입하거나 Mato를 이용할 수 없어요. 잠시 연결만 끊으려면 탈퇴 대신 로그아웃을 사용하세요.

제6조 (책임 제한 및 약관 변경)

Mato는 사용자의 로컬 PC와 브라우저에서 사용자가 지시한 작업을 보조하는 도구이며, AI 앱의 판단 오류나 외부 웹사이트의 정책 변경·장애로 인한 손해에 대해서는 책임을 지지 않아요. 약관이 바뀔 때는 이 문서의 시행일을 갱신해 알려 드려요.

제2부 · 개인정보처리방침

1. 수집하는 정보와 사용 목적

항목 수집 시점 사용 목적
Google 계정 식별자(sub), 이메일 주소 Google 로그인 및 API 요청 시 본인 인증, 로그인 유지, 관리자 판정, 일일 사용량 집계
YouTube 채널 ID의 단방향 해시(HMAC-SHA256) 내 멤버십 확인 시 원본 채널 ID를 저장하지 않고 유료 멤버십 가입 여부만 대조
PC 식별 해시, OS(Windows/macOS), PC 호스트명, 사용자가 저장한 브라우저 이름 로컬 브리지 연결 시 동시 연결 한도(PC·브라우저 수) 관리 및 기기 선택 해제 표시
일일 MCP 도구 호출 횟수 및 동시 실행 요청 ID MCP 도구 호출 시 하루 500회 한도 및 병렬 동시 처리 수 제한 적용

2. 외부 서버로 전송·저장하지 않는 정보

브라우저 데이터는 내 PC 안에서만 처리해요 웹페이지 본문, 열린 탭의 URL·제목, 화면 캡처 이미지, GIF 녹화 파일, 콘솔·네트워크 진단 로그, 북마크·방문 기록·다운로드 정보, 공유한 앱 창 화면은 사용자 PC의 로컬 Chrome과 로컬 AI 앱 사이에서만 오가며 계정 서버에 저장하지 않아요.

3. Google API 사용자 데이터 정책(Limited Use) 준수

Mato가 Google API를 통해 받는 정보의 사용과 다른 앱으로의 전송은 Google API Services User Data Policy(Limited Use 요건 포함)를 따라요. 로그인 및 멤버십 확인 목적 외에 광고, 제3자 판매, 외부 AI 모델 학습에는 절대 쓰지 않아요.

4. 보관 기간과 파기

  • 수집된 계정 정보는 서비스 이용 기간 동안 Supabase 보안 데이터베이스(행 수준 보안 RLS 적용)에 안전하게 보관해요.
  • 사용자가 회원탈퇴를 누르면 연결 기기, 일일 사용량, 병렬 설정, YouTube 채널 연동 기록을 즉시 영구 삭제해요.
  • 단, 회원탈퇴 후 재가입 방지 및 부정 이용 예방을 위해 복호화할 수 없는 Google 계정 단방향 해시(sub_hash)만 서비스 종료 시까지 분리 보관한 뒤 파기해요.

5. 개인정보의 국외 이전

Mato는 계정 인증, 유료 멤버십 확인 및 이용 한도 관리를 위해 클라우드 백엔드(Supabase)를 이용하며, 아래와 같이 최소한의 계정·연동 정보를 국외에 이전·보관해요.

항목 내용
이전받는 자 및 연락처 Supabase Inc. (문의: 마토 유튜브 채널 @Mato_coder ↗)
이전되는 국가 · 리전 일본 (도쿄 리전 ap-northeast-1)
이전 일시 및 방법 Google 로그인, 내 멤버십 확인, 로컬 브리지 연결 및 MCP 도구 호출 시 HTTPS 암호화 통신으로 전송

이전 목적 및 보유 기간 회원 인증, 멤버십 등급 확인, 일일·기기·동시 실행 한도 관리 / 회원탈퇴 시 즉시 파기(단, 재가입 방지를 위한 sub_hash는 서비스 종료 시까지 분리 보관 후 파기)

6. 이용자의 권리와 철회 방법

  • Chrome의 Mato 팝업에서 로그아웃, 선택한 연결 해제, 회원탈퇴를 언제든 직접 실행할 수 있어요.
  • Google 계정 보안 설정(Google 계정 연결된 앱 ↗)에서도 Mato의 Google·YouTube 접근 권한을 바로 철회할 수 있어요.
  • 북마크·방문 기록·다운로드·탭 진단 권한은 Mato 팝업 하단에서 원할 때 켜고 끌 수 있어요.
